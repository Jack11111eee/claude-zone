## v1.1 Requirements

Requirements for v1.1 (收尾与加固). 所有条目以 DESIGN.md v1.2 对应章节 + v1.0 复盘记录（RETROSPECTIVE.md「Deferred / v1.x Maintenance」）为准。REQ-ID 沿用各自治袭前缀。

### Consolidation（单源收敛）

- [ ] **CONSOL-01**: hook 内 zone 显示文案不再各自硬编码（LABELS dict），改由单一来源派生（zones/*.yaml `display` 或 bin 内部子命令输出），四处 hook 文案与 yaml 保持一致同源
- [ ] **CONSOL-02**: 派生逻辑变更后，现有 hook 行为无回归：提示行文案、护栏拒绝理由、pending 提示逐字不变（或仅变得更一致）

### Session Lifecycle（会话生命周期补全）

- [ ] **SESS-01**: SessionEnd hook 落实 DESIGN §9 设计：轻量 append 一个 lastSeen 事件（无 LLM 调用、无分类），已登记会话的 `zone list` 相对时间据此更新
- [ ] **SESS-02**: 未登记（unzoned）会话的 SessionEnd 保持零打扰：不 append 事件、不产生输出

### Guard Hardening（护栏加固）

- [ ] **GUARD-05**: maint Bash 黑名单补齐已知的非常规形态：`git clean` 附带 `-Xfd`/`-xfd` 等删除类旗标组合、命令名多空格形态（如 `git  clean`）仍被拦截
- [ ] **GUARD-06**: 护栏加固以测试矩阵固化：新增形态有独立测试用例，回归跑既有 §8.2 十用例全过（不因加固破坏 force-with-lease 放行等已有裁决）

### Packaging（发布收尾）

- [ ] **PACK-01**: 插件版本号语义化：plugin.json `0.0.1` → `1.0.0`，并在 README 标注版本对应关系（v1.0 里程碑 → 1.0.0 起）
- [ ] **PACK-02**: 发布核查：marketplace 本地安装升级路径可用（旧版安装后拉新版，行为预期不变），CHANGELOG 或 MILESTONES.md 记录 v1.1 变更
