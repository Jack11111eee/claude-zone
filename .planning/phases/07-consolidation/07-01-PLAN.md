# Phase 7 Plan 07-01: zone 文案单源收敛

**Goal**: `session_start.py` / `user_prompt_submit.py` / `pre_tool_use_write.py`（以及 `pre_tool_use_bash.py` 如引用）内的 `LABELS` dict 全部退役，文案改由 zones/*.yaml `display` 字段单源派生，前台行为零回归。

**Design Anchors（CODE SECTIONS）:**
- `bin/zone` `def zone_prompt_text(zone, repo_root=None)`（~L344）——`_zone-prompt` 的 prompt 提取器；本 plan 仿其形状加同族函数 `zone_display_text`
- `bin/zone` `def load_zone_def(zone, repo_root=None)`（~L912）——合并管线（内置→repo overlay→deep merge），display 已在其顶层字段
- `hooks/session_start.py:19` `LABELS = {...}`、`hooks/user_prompt_submit.py:21`、`hooks/pre_tool_use_write.py:18`——三处硬编码（值域：chore=杂活区, core=核心区, discuss=讨论区, maint=版本维护区）
- yaml 现值：`display: 核心 / 讨论 / 杂活 / 版本维护`（**无「区」后缀**；LABELS 有）——派生规则：`display + "区"`

**方案（bin 出数据，hook 转发——M-5 同构）：**

1. `bin/zone`：`_zone-prompt` 的 JSON 输出从 `{"zone", "prompt"}` 扩为 `{"zone", "prompt", "display"}`（`zone_display_text` 经 load_zone_def 同管线取值；显示文案 = `display` 字段，后缀在 hook 拼或不拼见 tasks 决策）。向后兼容：多一个 key 老消费者无感。
2. 三个（或四个）hook：删除 `LABELS`；提示行 `f"{LABELS[zone]}已就绪。"` → `f"{display}区已就绪。"`（display 从 `_zone-prompt` 响应取，或单独新增超轻内部子命令——见 tasks 决策）；`pre_tool_use_write.py` 的 `LABELS.get(zone, zone)` → 同源 `display`（该 hook 已调用 `_check-guard`，返回的 verdict 无 display——决策点）。
3. 文案格式保持逐字一致：v1.0 输出 `核心区已就绪。`，v1.1 后必须同串。

## Tasks

1. **bin: `_zone-prompt` 输出加 display 字段**
   - `zone_display_text(zone, repo_root=None) -> str`：load_zone_def → `data.get("display")`，缺失/空抛 ZoneDefError（与 prompt 同校验形状）
   - `cmd_zone_prompt` JSON 分支：`data` 加 `"display": display`
   - 非破坏：`_zone-prompt --json` 旧 key 不动
   - Verify: `zone _zone-prompt core --json` → `data.display == "核心"`；四个区全查
2. **hooks: 提示行单源化（session_start / user_prompt_submit）**
   - 删 LABELS；`ctx = f"{LABELS[zone]}已就绪。\n{prompt}"` → display 从 **同一次** `_zone-prompt` 响应取（零额外 subprocess 调用；就绪行后缀「区」在 hook 拼）
   - `session_start.py` 的 `if zone not in LABELS` 归一化判断改判 `ZONES` 集合（注意：该常量当前 hook 里没有——从 `_register-session` 响应区名判 unzoned 即可：`data.get("zone") in ("unzoned", None)` 反转逻辑，看现有判断改写）
   - Verify: 五向验收（前缀/no前缀/subagent/非startup/旧语法）回归 + 文案 diff 逐字同 v1.0
3. **hooks: 护栏文案单源化（pre_tool_use_write）**
   - 删 LABELS；deny 分支 `reason = f"{display}区护栏：本区禁止修改源码。..."`
   - display 来源：`_check-guard` JSON 输出扩 `"display"` 字段（deny/allow 都带，值从 `load_zone_def` 取——写侧加，hook 只读；missing 时 fallback `zone` 原名，degrade-to-open 精神）
   - Verify: 六象限矩阵回归（discuss deny / allow_paths 豁免 / unzoned allow / chore allow / bin 失败 allow / 文案逐字）
4. **单源性证明测试**
   - ZONING_HOME 隔离：临时 repo `.claude/zones/core.yaml` overlay 改 `display: 超核` → hook 输出 `超核区已就绪。（新会话实测或 hook 单测）`
   - 移除 overlay，输出还原 `核心区已就绪。`
   - Verify: 证明文案随 yaml 变（CONSOL-01 的「单源」语义）
